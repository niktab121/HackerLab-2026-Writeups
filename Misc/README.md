# Misc — systèmes simulés et dossiers incomplets

[Accueil](../README.md) · [Index général](../INDEX.md) · [Couverture](../reports/coverage.md)

Trois dossiers, dont un seul documenté techniquement :

- **Canary** : neutraliser les canaux du système Janus et modifier la trajectoire du drone simulé (Python, middleware, MAVLink, Flask). Reconstruction détaillée, statut **Partial**.
- **Conspiracy** : challenge mentionné, sans artefact ni énoncé exploitable. **Unsolved**.
- **Human After All — dossier vide** : dossier vide conservé comme tel, sans résolution inventée. **Unsolved**.

## Par où commencer

**[Canary](canary/README.md)** est le seul dossier Misc avec une chaîne technique ; les deux autres documentent explicitement l’absence de matière.
